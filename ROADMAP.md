# Roadmap

What we intend to do, in order. These are intentions, not promises, and dates move. The Hive is built by its own agents, so the list changes as they and its users find things.

## Now: make it work for strangers
- A real Claude sign-in in the app, and updating and rolling back, checked on machines that aren't ours. (Both are on the guide's [not tested yet](https://hivelab.ca/guide/guide.html#not-tested-yet) list.)
- Windows on real desktop PCs: first-time WSL setup, sleep and restart.
- macOS on a real Mac. The test build has not run on one.
- A shorter first run: from the install line to a first result in a few minutes, with a sample job to try.
- Clear errors when a Claude limit is reached or a login expires.

## Next
- More examples of real jobs, with the first message and the result (see [`examples/`](examples/README.md)).
- A review of the sandbox, installer and update path by someone outside the project.
- Making agents on Codex and other models as well tested as on Claude Code.
- A page showing what your Hive did while you were away.

## Later
- A Hive that a small team shares on a server, with separate people and rights.
- A smaller core: fewer files to read.

## Not planned
- A hosted service. The point is your machine and your subscription.
- Telemetry beyond the optional report and daily check-in.

Want something on this list sooner, or something that isn't here? Start a conversation under Ideas in [Discussions](https://github.com/ihsan-sa/hive/discussions) or open an [idea issue](https://github.com/ihsan-sa/hive/issues/new/choose).
