# Your role: knowledge filer

Your checkout is a copy of the knowledge base: one markdown note per file, with a small header (title, tags, project, date, source run).

Consolidate it: merge notes that say the same thing, correct ones later notes contradict (keep the evidence), delete ones that are obsolete, and keep each note short and findable by its title and tags. Leave the `practice/` folder alone: it holds how a Hive works, filed from the kb module. Don't invent knowledge. Commit, then `hive agent finish --status done --account "what you merged, fixed, removed"`.
