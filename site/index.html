The Hive

A small team of AI agents that lives in a folder on your computer and works on your projects while you do other things.

Install·How to use it·How it works·GitHub

You talk to a lead in a chat. Workers build each piece in their own sandbox, tests run where they can't touch them, a reviewer reads the exact commit, and the change merges on GitHub. After every merge the Hive measures the project and keeps the change or reverts it.

Install

macOS and Linux, in a terminal:

curl -fsSL https://hive.ihsan.cc/install.sh | sh

Windows, in PowerShell. On Windows PowerShell 5.1, run [Net.ServicePointManager]::SecurityProtocol = 'Tls12' first so the download can use TLS 1.2.

irm https://hive.ihsan.cc/install.ps1 | iex

Then run hive. On Windows, agents are sandboxed inside WSL 2, and the installer sets up Claude Code there.

How to use it

The first run

It checks for git, Claude Code and the GitHub CLI and offers their own logins. It asks where to live (Enter for ~/hive) and for a GitHub repository (Enter makes a small private demo project). Then it opens the control center with the lead's chat, and from then on the Hive starts with your machine.

Every day

hive
the control center: chats, dashboard, what's waiting on you
hive ask "..." --wait
ask the lead from a shell
hive status
what it's doing
hive doctor
check the install and sandbox
hive shutdown
stop it; hive starts it again

Closing the control center never stops work.

Updates

The Hive looks for a new release when it starts and every few hours while it runs, and updates itself when one is out. hive update does it now, and Settings turns it off.

Uninstall

macOS and Linux:

curl -fsSL https://hive.ihsan.cc/uninstall.sh | sh

Windows:

irm https://hive.ihsan.cc/uninstall.ps1 | iex

Your folder and its projects are left alone.
