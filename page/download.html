Download Hive

One file, double-click, and you are in the Hive. The terminal install line still works too: curl -fsSL https://hivelab.ca/install.sh | sh on Linux, irm https://hivelab.ca/install.ps1 | iex in Windows PowerShell, curl -fsSL https://hivelab.ca/install-mac.sh | sh on a Mac.

Windows 10/11 — Hive-Setup.exe Mac with Apple chip (M1 or later) — Hive-mac-arm64.zip Mac with Intel chip — Hive-mac-x64.zip Linux: Ubuntu, Debian, Mint — Hive.deb Linux: Fedora — Hive.rpm

Windows says "Windows protected your PC"

That is expected: the app is not signed yet. Press More info, then Run anyway. Windows may ask permission once, and may need one restart; open Hive again afterwards and it carries on.

Mac says "Hive" Not Opened

Which Mac? Apple menu, About This Mac: "Chip Apple M…" takes the Apple chip file, "Processor … Intel" the Intel one. Open the downloaded zip (Safari unpacks it for you), drag Hive into Applications and double-click it.

  1. Press Done (not Move to Trash).
  2. Open System Settings, Privacy & Security, scroll down to Security. It says "Hive" was blocked to protect your Mac. Press Open Anyway, then confirm with your password or Touch ID.
  3. Hive opens. The Mac asks this once only.
Linux

The .deb is for Ubuntu, Debian, Mint and other systems that install with apt, on an Intel or AMD PC. Double-click it, then open Hive from your applications. If it says there is no app installed for "Debian package" files (some Ubuntu versions), or it opens an archive instead, open a Terminal in your Downloads folder and run sudo apt install ./Hive-linux-amd64.deb.

The .rpm is for Fedora on an Intel or AMD PC. Double-click it and press Install in Software, or open a Terminal in your Downloads folder and run sudo dnf install ./Hive-linux-x86_64.rpm.

On Arch, an ARM board or another Linux, use the install line instead: curl -fsSL https://hivelab.ca/install.sh | sh

Already have Hive? Update it

Download the new file from the button above, then:

  • Windows: run the new Hive-Setup.exe. Hive can stay open: the installer closes it, puts the new one in its place and keeps your window and sign-in. If Hive does not come back by itself, open it from the Start menu.
  • Mac: quit Hive first (Hive menu, Quit). Open the new zip, drag Hive into Applications and choose Replace, then open Hive. Your window and sign-in stay.
  • Linux: double-click the new .deb, or run sudo apt install ./Hive-linux-amd64.deb, over the old one (on Fedora the new .rpm, or sudo dnf install ./Hive-linux-x86_64.rpm). An open Hive keeps working; the next time you open it, it is the new one.

Nothing is lost either way: your Hive and its chats live on your machine, not in the app.
